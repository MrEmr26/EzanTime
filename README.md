# 🕋 EzanTime (V5.5.1 Mekke)

> **Die ultimative, seniorenfreundliche islamische Begleit-App mit minutengenauen Diyanet-Gebetszeiten, Qibla-Kompass, Zikirmatik und automatischem Update-System.**

---

## ✨ Features & Highlights

- 🕌 **Präzise Gebetszeiten:** Minutengenaue Berechnung über die AlAdhan API (Standard: Diyanet / DİTİB Methode 13, umschaltbar auf MWL & ECFR).
- 👴 **Seniorenfreundliches Design:** Extra große, gut lesbare Ziffern (28-38sp), hohe Kontraste und eine barrierefreie Taskleiste.
- 🧭 **Kıble Pusulası:** Interaktiver Qibla-Kompass mit Kaaba-Nadel und Live-Entfernung nach Mekka in Kilometern.
- 📿 **Zikirmatik:** Digitaler Tesbih-Zähler mit voreingestellten Zikirlere (Subhanallah, Elhamdulillah etc.) und haptischem Vibrationsfeedback.
- 📅 **Dini Günler (2025 - 2026):** Islamische Feiertage und Kandil-Nächte mit Live-Countdown.
- ⚡ **Auto-Updater:** Automatischer Hintergrund-Check für nahtlose Hotfixes direkt über GitHub Releases.
